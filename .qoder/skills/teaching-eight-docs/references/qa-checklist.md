# 成品自检清单

生成后先跑 `validate_docs.py`，再人工抽查。报告写入交付目录 `校验报告.md`。

## A. 致命问题（必须修复后才交付）

- [ ] 文档打不开或页数异常（如 0 页、空白页占多数）
- [ ] 出现 `{{`、`}}`、`TODO`、`待补充` 之外的模板占位符
- [ ] 出现模板原课程信息：原课程名、课程代码、原教师名、原班级、原章节名
- [ ] 课程名称/代码/学分/学时在不同文档之间不一致
- [ ] 章节学时合计 ≠ 总学时
- [ ] 考核比例合计 ≠ 100%
- [ ] 用户提供的 2/6 文件被修改
- [ ] 缺失 2 或 6，且用户未授权代做

## B. 结构问题（对照模板）

- [ ] 1 号：标题 + 9 行 2 列表格，9 个字段齐全
- [ ] 3 号：封面 6 字段；八个一级标题齐全；10 张表格齐全；表 5 每章 8 行
- [ ] 4 号：封面；一、课程简介；教学目的与教学要求；每章含「本章教学目标和要求/重点/难点/教学方式」；每次课含 9 个固定栏目
- [ ] 5 号：封面；标题；5 列表格；说明 3 行
- [ ] 7 号：12 行 5 列表格；平时/期末合并正确；备注行存在
- [ ] 8 号：标题；4 个加粗字段；使用教材与参考教材齐全
- [ ] 页面 A4、页边距 2.8/2.6/2.8/2.6
- [ ] 正文字体宋体 10.5pt；标题字号符合规范

## C. 内容质量

- [ ] 课程目标可测量，且与毕业要求指标点对应
- [ ] 大纲表 5 的「学习目标/重难点/学情分析/课前准备/教学方法/课后作业」无空缺
- [ ] 教案每次课的「教学组织」是流程描述，不是空话
- [ ] 教案「作业布置」有具体页码/题号；没有则标注待补充
- [ ] 思政点与本章内容相关，不是通用套话
- [ ] 进度表周次连续、无重复、无跳周；节假日行保留
- [ ] 教材/参考书在 1/3/4/8 中完全一致
- [ ] 英文课程名大小写与拼写正确
- [ ] 无 `###`、`……`、明显重复段落

## D. 交付提醒（写入报告，由用户决定是否修改）

- 未生成的 7/8 及原因（用户未提供考核方案/书目）
- 待补充字段清单（课程代码、比例、签字人、日期、作业页码等）
- 由 AI 推导、建议教师复核的内容（学情分析、思政设计、自我总结）
- 2/6 是复制还是代做；代做课件的替换提醒
- 课件页数与章节覆盖是否匹配（若可统计）

## 报告格式

```markdown
# 教学八大件检查报告

课程：<名称>（<代码>）
生成时间：<日期>
交付目录：<路径>

## 1. 已生成
- 1、课程简介.docx — 通过
- 3、课程教学大纲.docx — 2 个警告

## 2. 直接收录（未修改）
- 2、教师简历（姓名）.docx
- 6、教学课件/（N 个文件）

## 3. 未生成
- 7、课程考核方案.docx — 未提供考核方案

## 4. 必须人工补充
- 课程代码
- 审核人

## 5. 警告
- 第 3 章学时 18，与进度表 16 不一致
- 教案第 2 章作业页码为推断值，请核对

## 6. 建议复核
- 学情分析、思政设计由 AI 根据课件推导
```
