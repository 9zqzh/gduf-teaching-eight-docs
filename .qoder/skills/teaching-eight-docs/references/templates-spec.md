# 教学八大件模板规范

本文件是生成 Word 文档的唯一版式依据。所有尺寸单位为厘米，字号单位为磅（pt）。
模板来源：`八大件模板文件/` 下四门课程的教学文件，以数学分析III（docx）与常微分方程（教案 docx）为主样本。

## 0. 通用设置

| 项目 | 规范 |
|---|---|
| 纸张 | A4，21.0 × 29.7 |
| 页边距 | 左 2.8、右 2.6、上 2.8、下 2.6（正文宽 15.6） |
| 正文中文 | 宋体，10.5pt（五号） |
| 正文西文 | Times New Roman |
| 行距 | 正文 1.5 倍；表格内单倍行距 |
| 首行缩进 | 中文正文段 2 字符（10.5pt 时约 21pt） |
| 表格 | 全边框（0.5pt 实线），表头居中加粗，内容居中或左对齐，垂直居中 |
| 页码 | 3、4、7 号文档页脚居中显示页码；1、5、8 号不显示 |

命名规范（交付目录内）：

```
1、课程简介.docx
2、教师简历（姓名）.docx
3、课程教学大纲.docx
4、课程教案.docx
5、教学进度表.docx
6、教学课件/
7、课程考核方案.docx
8、教材与参考书目.docx
```

交付目录命名：`<学期>-<教师姓名><课程名称>`，例如 `2026-2027-1张三数学分析III`。

## 1. 课程简介

- 页面：A4，页边距 3.175 / 3.175 / 2.54 / 2.54，docGrid 行网格 linePitch 312。
- 标题：「课程简介」，宋体 18pt 加粗，居中，1.5 倍行距，段前后 0；标题后空一行（同样 1.5 倍行距）。
- 一张 9 行 × 2 列表格，列宽 2.94 / 12.70（总宽 15.64cm），表格左对齐（不居中、不缩进），右侧可超出右边距。
- 行高（twips）：547 / 520 / 547 / 1659 / 535 / 520 / 520 / 572 / 572。
- 单元格文字一律宋体 10.5pt：首列（字段名）加粗、左对齐；内容列常规、左对齐。
- 行距：课程名称、课程代码、课程性质、修读条件、教材、「参考书」字段行用 1.4 倍行距；开设目的单倍行距；主要内容 / 参考书 / 考核方式三行固定 18pt 行距，段前后 0。
- 首行缩进：主要内容 21pt，参考书 22.9pt。
- 固定字段（顺序不可改）：

| 字段 | 内容要求 |
|---|---|
| 课程名称 | 与教学大纲、进度表完全一致 |
| 课程代码 | 学校课程编码 |
| 课程性质 | 如「学科基础必修课」 |
| 开设目的 | 80–200 字，说明课程定位、能力培养、后续作用 |
| 修读条件 | 先修课程；无则写「无」 |
| 主要内容 | 按章节主题罗列，不超过 100 字 |
| 教材 | 作者、书名、版次、出版社、年份 |
| 参考书 | 编号「1. 2. …」，每条含作者、书名、出版社、年份 |
| 考核方式 | 分两行写「期末：…（共占X%）」和「平时：…（共占Y%）」 |

注意：「参考书」一栏是同一单元格内换行，生成时每条一段，编号用「1.」而非「[1]」。

## 2. 教师简介（教师提供，默认不改）

- 标题：「教师简介」，黑体/宋体 24pt 加粗，居中。
- 一张 5 行 × 7 列表格。合并规则：
  - 第 1–2 行的第 1–4 列纵向合并（姓名/性别/出生年月/职称职务）；
  - 第 1 行第 5–6 列合并为「毕业院校」，第 2 行拆为「本科」「博士」；
  - 第 1–2 行第 7 列纵向合并（参加工作时间）。
- 字段：姓名、性别、出生年月、职称/职务、本科毕业院校、博士毕业院校、参加工作时间、承担过的课程、目前承担的课程。
- 使用规则：
  - 用户提供成品时**原样复制**到交付目录，不打开、不改写。
  - 用户未提供且明确要求代做时，用 `build_docs.py --docs 2` 按上表生成，缺项写「（待补充）」并在报告中列出。

## 3. 课程教学大纲

### 3.1 封面

顶部居中放置学院标识图（`assets/images/cover_logo.jpeg`，宽 2.20）与标题图（`assets/images/cover_title.png`，宽 10.54），其下 6 行 16pt 宋体加粗字段，值带下划线，字段间空一行：

```
课程名称：    <课程名称>
课程代码：    <课程代码>
开课单位：<开课单位>
制定人：        <制定人>
审核人：        <审核人>
制定时间：   <YYYY年M月>
```

空 3 行后居中「广东金融学院教务处 制」（14pt），分页。

### 3.2 正文标题与章节

- 标题：`《<课程名称>》课程教学大纲`，22pt 居中。
- 一级标题（12pt，宋体）：一、课程信息；二、课程简介；三、课程目标；四、课程目标与毕业要求的对应关系；五、教学内容、要求及进度安排；六、考核与评价★；七、教材、参考文献与其他教学资源；八、说明。
- 固定尾句：`本大纲经课程所属学院制定人、审订人、审批人签字后方可生效，以上内容由课程所属学院负责解释。`

### 3.3 表格结构（共 10 张，顺序固定）

**表 1 课程信息**（9 列，列宽 1.98/1.89/2.06/2.02/2.10/0.32/1.51/1.73/2.02；合并见下）

| 行 | 结构 |
|---|---|
| 1 | 课程名称 ｜ 中文名（跨 8 列） |
| 2 | 课程名称 ｜ 英文名（跨 8 列） |
| 3 | 课程编码 ｜ 编码（跨 2 列）｜ 课程性质 ｜ 必修/选修（跨 5 列，选中项加 √） |
| 4 | 课程类型 ｜ 通识教育课程 / 拓展教育课程 / 学科基础课程 / 实践课程 / 专业课程（跨 8 列，保留四类并标注选中项） |
| 5 | 适用专业 ｜ 专业（跨 8 列） |
| 6 | 开课部门 ｜ 部门（跨 3 列）｜ 课程负责人（跨 2 列）｜ 姓名（跨 3 列） |
| 7 | 学分 ｜ 数值（跨 3 列）｜ 学时 ｜ 数值（跨 4 列） |
| 8 | 合并整行：`总学分：X｜理论：X｜实验：X｜实践：X｜总学时：X｜理论：X｜实验：X｜实践：X` |
| 9 | 授课语言 ｜ 中文（跨 8 列） |
| 10 | 先修课程 ｜ 课程（跨 8 列） |

**表 2 课程简介**：1×1 表格，内部按 6 段：

```
课程的学科背景：…
开设目的和意义：…
主要内容：…
课程特色与思政教育：…
教学与考核方式：…
学生通过学习该课程可获得的知识、技能、能力和素养★：…
```

**表 3 课程目标**：1×1 表格，每条一段，格式 `课程目标N：…`。

**表 4 课程目标与毕业要求对应关系**（4 列：5.30 / 1.84 / 7.64 / 3.22，总宽 18，居中略超版心，与模板一致）

- 首行：毕业要求 ｜ 毕业要求分解指标点（跨 2 列）｜ 课程目标。
- 每条一行，课程目标列写 `1（H）`、`2（M）` 等；多个目标各占一行（模板如此）。

**表 5 教学内容、要求及进度安排**（4 列，列宽约 2.04 / 5.87 / 2.09 / 4.82）

每章固定 8 行：

| 行 | 内容 |
|---|---|
| 1 | `<第X章：章名>`（跨 2 列）｜ `学时：N` ｜ `支撑课程目标：…` |
| 2 | 主要内容 ｜ 正文（跨 3 列） |
| 3 | 学习目标★ ｜ 正文（跨 3 列） |
| 4 | 学习重难点★ ｜ 正文（跨 3 列） |
| 5 | 学情分析 ｜ 正文（跨 3 列） |
| 6 | 学生课前准备 ｜ 正文（跨 3 列） |
| 7 | 教学方法、方式★ ｜ 正文（跨 3 列） |
| 8 | 课后作业 ｜ 正文（跨 3 列） |

**表 6 考核方式**（4 列：考核方式 / 考核要求 / 比重（%） / 对应的课程目标），一行一个考核项，末行合计比重应为 100。

**表 7 考核方式评价标准**（7 列，列宽 2.00/3.75/2.65/2.36/2.33/2.09/2.05）

- 第 1 行：考核方式 ｜ 基本要求 ｜ 评价标准（跨 5 列）
- 第 2 行：同样三列 + 优秀（90-100分）/ 良好（80-89分）/ 中等（70-79分）/ 及格（60-70分）/ 不及格（0-59分）
- 之后每个考核项一行，5 档描述按该考核项的实际标准填写。

**表 8 课程目标评价标准**（7 列，列宽 2.25/3.51/2.54/2.70/2.22/2.07/2.19）：结构同表 7，首列为 `课程目标N`，第二列为考核依据。

**表 9 教材、参考文献与其他教学资源**：1×1 表格，内含：

```
1.选用教材：…
2.参考文献：
[1] …
3.网络资源：
1．…
```

**表 10 签字**（3 列）：`制定人：X` ｜ `审订人：X` ｜ `审批人：X`；末行右侧 `时间：YYYY年M月D日`。

## 5. 教学进度表

- 封面同 3 号文档。
- 标题：`<课程名称>  课 程 教 学 进 度 表`，15pt 加粗居中。
- 下一行：`学时：  80          学分：5`，14pt。
- 表格 5 列（1.58 / 2.68 / 7.27 / 1.87 / 2.20）：周次 / 课程章节 / 教 学 内 容 / 授课/学时 / 教学方式。
- 每行一次课；节假日单独一行，后三列留空。
- 周次写法 `1(1)`、`1(2)`、`2(1)`…；最后一次课写 `16`（整数周）。
- 表格后固定说明（宋体加粗）：

```
说明：
1.因为课时量较少，所以授课难度要适度降低；教材上的加*号的内容和小字内容都不讲。
2.实际操作中，任课教师在确保完成教学任务的前提下，可以根据实际情况进行微调。
```

第 1 条按课程实际情况改写，不得原样套用不相关表述。

## 6. 教学课件（教师提供，默认不改）

- 目录按教学单元分子文件夹（如 `1/1-1.ppt`），文件数量与章节/课时对应。
- 用户提供时整套复制进交付目录，不修改。
- 用户未提供且明确要求代做时，只能生成**提纲版 PPTX**（每章一个文件，标题 + 要点），并在报告中标注「提纲版，需教师替换为正式课件」。

## 7. 课程考核方案（用户提供考核要求时才生成）

- 页面：A4，页边距 3.175 / 3.175 / 2.54 / 2.54，docGrid 行网格 linePitch 312，页脚含页码。
- 标题：「广东金融学院课程考核方案」，黑体 16pt、**不加粗**、居中，固定行距 20pt，段前 2.5pt、段后 7.8pt。
- 下一行：`教学单位：<部门>` + 若干空格 + 日期，12pt，固定行距 20pt。
- 表格列宽 2.69 / 2.58 / 5.42 / 2.50 / 3.00（总宽 16.19cm），左对齐（不居中、不缩进），右侧可超出右边距。
- 表内文字一律宋体、**一律不加粗**；标签单元格居中，评分标准列左对齐。
- 表头 4 行 + 按实际考核项目数的项目行 + 1 行备注，不留空行补位：

| 行 | 结构 |
|---|---|
| 1 | 课程名称 ｜ 名称（跨 2 列）｜ 任课教师 ｜ 姓名 |
| 2 | 考试班级 ｜ 班级（跨 2 列）｜ 课程性质 ｜ 专业必修课等完整表述 |
| 3 | 期末考核方式 ｜ 纯文字，如「考查（课程论文）」（跨 4 列，不用勾选项） |
| 4 | 总评成绩构成 ｜ 项目 ｜ 评分标准（跨 3 列，写「项目（比例）」与具体要求） |
| 5… | 平时成绩（X%）纵向合并 ｜ 各子项（比例%） ｜ 评分标准（跨 3 列） |
| … | 期末成绩（Y%）纵向合并 ｜ 子项（比例%） ｜ 评分标准（跨 3 列） |
| 末行 | 备注 ｜ 内容（跨 4 列，顶端对齐） |

- 行高（twips）：表头行 693、694，项目行 567，备注行 2369。
- 行距：表头 4 行固定 20pt（段前 2.5 / 段后 7.8），第 4 行「总评成绩构成」固定 15pt，项目行固定 12pt；备注 12pt、固定 30pt、段前后 5pt、首行缩进 24pt。
- 平时 + 期末比例必须合计 100%；各子项比例合计须与所属大类一致。
- 表格下：`注：以上成绩构成项目及比例请根据课程实际情况填写。`（10.5pt）
- 末尾居中：`任课教师签字：`（10.5pt）

## 8. 教材与参考书目（用户提供书目时才生成）

## 9. 字段来源优先级

| 字段 | 第一来源 | 第二来源 | 缺失处理 |
|---|---|---|---|
| 课程名称/代码/学分/学时/性质/专业 | 用户填写的课程信息 | 教学大纲/人才培养方案 | 必须询问，不猜 |
| 教师姓名/职称/单位 | 教师简介 | 用户说明 | 必须询问 |
| 章节与学时 | 教学大纲/进度表 | 课件目录、人才培养方案 | 按总学时拆分并标注 |
| 章节内容/重难点/思政 | 课件 | 教材目录、大纲 | 生成草案并标注待教师确认 |
| 考核比例 | 考核方案 | 大纲表 6 | 默认 平时30% + 期末70%，需确认 |
| 教材/参考书 | 教材与参考书目 | 大纲表 9、课程简介 | 未提供则写「（待补充）」 |
| 制定/审核/审批人 | 课程信息 | 以往模板 | 未提供则写「（待补充）」 |
| 日期 | 用户指定 | 当前学期对应月份 | 不编造，询问确认 |

## 10. 禁止事项

- 不得把模板原课程（如数学分析III、常微分方程）的课程名、代码、章节、教师、班级带入新课程。
- 不得编造教材版本、出版年份、课程代码、学时、考核比例、签字人。
- 不得改动用户提供的 2 号、6 号文件。
- 不得删除模板固定栏目或改字段名称。
